About

Built with Tauri (Rust) and modern web technologies.

ani-cli

Trela uses ani-cli to resolve and play episodes. If playback stops working, anidb.app (what ani-cli searches) may have changed something — updating ani-cli often fixes it once a new version ships. 


            


            

              
Movies & Series

              

                Movies and Series use the TMDB API for search/browse metadata (requires a free
                API key — create one at themoviedb.org → Settings → API, no cost, no card) and
                both MovieBox and 4KHDHub for playback — the Watching page's
                Source picker lists options from both together, tagged by provider.
              

              

                
                
              

              

            


            

              
Downloads

              

                When a movie/series source won't stream reliably, "Download & Play" on the Watching page saves
                it under your Downloads folder in a Trela subfolder instead.
              

              

              
              

            


            

              
Data

              

                Export your wishlist, continue-watching list, and preferences to a file, or restore them on
                another install. Your TMDB API key isn't included — re-enter it above after restoring.
